# LLM翻訳プラグイン

テキスト・Webページ・画像をLLMで翻訳するChrome拡張機能です。クラウドAPIとローカルLLMに対応しています。

## 対応プロバイダー

- OpenRouter
- Google Gemini
- Cerebras
- Z-AI
- Ollama
- LM Studio
- Chrome Gemini Nano（Prompt APIを利用できる環境が必要）

## インストール

1. このリポジトリをクローンまたはダウンロードします。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」からリポジトリのディレクトリを選択します。
4. ツールバーの拡張アイコンを開き、接続先・APIキーまたはサーバーURL・モデルを設定して「変更を保存」を押します。

Ollama・LM Studioを使う場合は、あらかじめローカルサーバーを起動してください。APIの利用には、提供元の料金や利用条件が適用されます。

## 使い方

| 対象 | 操作 |
| --- | --- |
| 選択したテキスト | 右クリック →「LLM翻訳」 |
| ページ全体 | 右クリック →「LLMページ全体翻訳」 |
| 画像内のテキスト | 画像を右クリック →「LLM画像翻訳」（LM Studioのみ） |
| Xの投稿 | 投稿の「LLM翻訳」ボタン |
| YouTubeのコメント | コメントの「JP」ボタン |

選択テキストは `Ctrl+Shift+T`（macOSは `Cmd+Shift+T`）でも翻訳できます。画像翻訳には画像入力に対応したモデルが必要です。

ページ全体翻訳では、数字・記号だけのテキストと、かなを含む日本語のテキストを翻訳対象から除外します。英字などが混在する文や漢字だけの文は対象に残します。

設定画面の「翻訳」で翻訳への指示やX・YouTube連携を変更できます。「動作確認」では保存前の設定で翻訳を試せます。

翻訳への指示には文体・用語などの方針を指定してください。JSONや区切り文字の出力形式は自動で指示します。旧版の区切り文字保持の定型文が残っている場合は、その部分だけ自動で除去します。

OpenRouter・Cerebras・Z-AI・LM Studioの「推論（Thinking）」は、接続先ごとにすべての翻訳で使う推論量を指定します。既定ではモデルの設定に従います。OFFで生成時間を短縮できる場合がありますが、対応する段階や訳の品質はモデルによって異なり、OFFにできないモデルもあります。Z-AIではON/OFFを指定できます。

## データの扱い

翻訳対象のテキストや画像は、設定した接続先へ送信されます。APIキーを含む設定はChromeの拡張ストレージに保存され、Chromeの同期設定によっては他の端末にも同期されます。

## 開発

```sh
bun install
bun run lint
bun run test
```

ビルドは不要です。コード変更後は `chrome://extensions/` で拡張を再読み込みし、翻訳対象のページも再読み込みしてください。
