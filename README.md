# LLM翻訳プラグイン

テキスト・Webページ・画像をLLMで翻訳するChrome拡張機能です。クラウドAPIとローカルLLMに対応しています。

## 対応する接続方式

- OpenAI互換API（Chat Completions）
- Google Gemini API
- Chrome Gemini Nano（Prompt APIを利用できる環境が必要）

OpenAI互換APIはベースURLを自由に指定できます。OpenRouter・Cerebras・Z-AI・LM Studio・Ollamaをプリセットから選択でき、カスタム接続も設定できます。Gemini APIとChrome内蔵モデルは専用の接続方式を使います。

## インストール

1. このリポジトリをクローンまたはダウンロードします。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」からリポジトリのディレクトリを選択します。
4. ツールバーの拡張アイコンを開き、接続方式・接続先・モデルを設定して「変更を保存」を押します。

Ollama・LM Studioを使う場合は、あらかじめローカルサーバーを起動してください。APIの利用には、提供元の料金や利用条件が適用されます。

## 接続の設定

OpenAI互換APIではプリセットを選び、必要に応じてベースURLとAPIキーを入力します。ベースURLは `http://localhost:1234/v1` のように、`/chat/completions` より前の部分を指定してください。モデルは一覧から選ぶか、モデルIDを入力してEnterで確定できます。一覧を取得できない接続先でも手入力で使用できます。

URL・APIキー・モデル・推論設定はプリセットごとに保持します。既存の設定も引き継ぎます。URLを変更すると、その接続先のAPIキーはクリアされます。「動作確認」では保存前の設定で翻訳を試せます。

「生成途中から順次表示する」は、ストリーム非対応の接続先ではOFFにしてください。プリセットは推論設定や構造化出力などのAPI差分も適用します。画像翻訳も、選択中の接続先のOpenAI互換API（`/chat/completions`）を利用します。

モデル一覧は設定画面を開いたときとプリセットを切り替えたときに取得します。料金情報を取得できるモデルでは、モデル欄の下に入力・出力単価（100万トークンあたりの米ドル）を表示します。

## 使い方

| 対象 | 操作 |
| --- | --- |
| 選択したテキスト | 右クリック →「LLM翻訳」 |
| 選択したテキストの要約 | ドラッグで選択 → 右クリック →「LLM要約」 |
| ページ全体 | 右クリック →「LLMページ全体翻訳」 |
| 画像内のテキスト | 画像を右クリック →「LLM画像翻訳」（OpenAI互換API / Chrome Gemini Nano） |
| Xの投稿 | 投稿の「LLM翻訳」ボタン |
| YouTubeのコメント | コメントの「JP」ボタン |

選択テキストは `Ctrl+Shift+T`（macOSは `Cmd+Shift+T`）でも翻訳できます。画像翻訳には画像入力に対応したモデルとAPIが必要です。OpenAI互換APIの接続先が画像入力を拒否した場合は、そのエラーを表示します。Chrome Gemini Nano は画像入力の利用可否を実行時に確認します。初回は設定の「モデルを準備」から準備画面を開き、モデルをダウンロードしてください。テキストと画像の利用可否は個別に表示します。準備済みの場合、翻訳時のモデル読み込みは自動で行います。

翻訳・要約は、ストリーム対応の接続先では生成途中から表示し、非対応またはストリームOFFの場合は一括表示します。Chrome Gemini Nano は選択テキスト・画像・要約と長さ調整・X・YouTube・ページ翻訳に対応します。ページ翻訳と選択範囲の置換では途中の訳文をパネルに表示し、本文への反映は結果の検証後に行います。

選択翻訳のポップアップでは、結果の下に追加指示を入力して「送信」できます（`Enter`で送信、`Shift+Enter`で改行。IMEの変換確定では送信しません）。たとえば「中国語のままなので、日本語に翻訳し直してください」「もっと自然な表現にしてください」と指示できます。原文・初回の翻訳方針・接続先とモデル・それまでの会話を引き継ぎ、前の回答と追加指示は折りたたんで確認できます。送信に失敗した場合は前の回答と入力を保持するため、そのまま再送できます。

会話はポップアップを閉じるか、新しい選択翻訳を始めると終了します。履歴はブラウザのセッション内だけに保持し、追加指示のたびに、初回のシステム指示を変更せず、原文・回答・追加指示をAPIの会話ロールに分けて渡します。会話の途中に新しい翻訳プロンプトは挿入しません。現時点では選択翻訳のポップアップ表示が対象です（ページ内置換・画像翻訳・ページ全体翻訳は対象外）。

要約のショートカットは `chrome://extensions/shortcuts` を開き、「LLM翻訳プラグイン」の「選択したテキストを要約」に好きなキーを割り当ててください。既定では未割り当てです。文章を選択して設定したキーを押すと要約できます。

要約はページ内のポップアップに日本語で表示します。ストリーム対応の接続先では、初回の要約も長さ調整も生成途中から順次表示し、非対応の接続先では完了後に一括表示します。「短く」「長く」で原文と現在の要約をもとに調整し、「コピー」で結果をコピーできます。翻訳と同じ接続先・モデルを使用し、翻訳の表示設定や翻訳への指示には影響されません。調整に失敗した場合は直前の結果を残し、再試行できます。

ページ全体翻訳では、数字・記号だけのテキストと、かなを含む日本語のテキストを翻訳対象から除外します。英字などが混在する文や漢字だけの文は対象に残します。

翻訳は本文（`main`・`article`など）、通常の文章、ナビゲーション・メニューなどの補助領域の順に開始します。同じ優先度ではページ内の順序を保ち、本文内の補助領域も後回しにします。対象の補助領域を省略することはありません。

設定画面の「翻訳」で翻訳への指示やX・YouTube連携を変更できます。「動作確認」では保存前の設定で翻訳を試せます。

「選択したテキストの翻訳結果」を「ページ内で置換」にすると、右クリック・ショートカットによる選択翻訳で選択部分を直接書き換えます。選択した文章全体を文脈として翻訳し、リンク先・装飾・段落構造を保持します。段落内のリンクや装飾は訳文の語順に合わせて移動できます。「原文に戻す」で新しい置換から順に戻せます（ページを再読み込みするまで）。入力欄・画像を含む範囲、要素をまたぐ選択の端がリンクなどの途中にある範囲、入れ子の段落はポップアップで表示します。モデルの出力とHTMLの対応が不正な場合やページが更新された場合は上書きしません。既定はポップアップ表示です。

LM Studioのページ全体翻訳にも「ページ翻訳の処理設定」の「同時リクエスト数」（1〜20）が適用されます。変更した値は次に開始するページ全体翻訳から使用します。

翻訳への指示には文体・用語などの方針を指定してください。JSONや区切り文字の出力形式は自動で指示します。旧版の区切り文字保持の定型文が残っている場合は、その部分だけ自動で除去します。

OpenRouter・Cerebras・Z-AI・LM Studioの「推論（Thinking）」は、接続先ごとにすべての翻訳で使う推論量を指定します。既定ではモデルの設定に従います。OFFで生成時間を短縮できる場合がありますが、対応する段階や訳の品質はモデルによって異なり、OFFにできないモデルもあります。Z-AIではON/OFFを指定できます。

モデル選択欄では、スペース区切りで複数の語を入力すると、すべての語を含む候補に絞り込めます（例: `gemini flash`）。語順や大文字・小文字は問いません。

## データの扱い

翻訳・要約対象のテキストや画像（要約の調整時は現在の要約も）は、設定した接続先へ送信されます。APIキーを含む設定はChromeの拡張ストレージに保存され、Chromeの同期設定によっては他の端末にも同期されます。

## 開発

```sh
bun install
bun run lint
bun run test
```

ビルドは不要です。コード変更後は `chrome://extensions/` で拡張を再読み込みし、翻訳対象のページも再読み込みしてください。
