# 手動スモークテストチェックリスト

自動テストで守れない Chrome API / DOM / 外部 API 依存の挙動を検証する共通手順。
各フェーズの作業単位ごとに**関連項目**を、フェーズ6では**全項目**を実施する。

前提: `chrome://extensions` でデベロッパーモード有効、本リポジトリを「パッケージ化されていない
拡張機能を読み込む」でロード。コード変更後は必ず拡張をリロードし、**テスト対象タブも再読み込み**する
（古い content script が残るため）。

## 0. 起動・基本

- [ ] 拡張ロード時に service worker のエラーが出ない（chrome://extensions → 「エラー」なし）
- [ ] popup が開き、コンソールにエラーがない
- [ ] オプション保存 → popup を閉じて再オープン → 設定が復元される

## 1. 選択テキスト翻訳

- [ ] 任意ページでテキスト選択 → 右クリック → コンテキストメニューから翻訳 → ポップアップ表示
- [ ] キーボードショートカット（Ctrl+Shift+T / Cmd+Shift+T）で同様に動く
- [ ] ストリーミング対応プロバイダーで逐次表示される
- [ ] ポップアップ外クリックで閉じる。**20回開閉してもリスナーが増えない**
      （DevTools console で `getEventListeners(document)` の件数確認 — フェーズ5）
- [ ] 翻訳中に閉じた場合にエラーが出ない（キャンセル経路）
- [ ] iframe 内のテキスト選択でも動く（all_frames 検証）

## 2. ページ翻訳

- [ ] コンテキストメニュー「ページを翻訳」で全文翻訳が進行し、進捗表示が出る
- [ ] キャンセルが効く
- [ ] 長いページ（チャンク分割が複数回走る規模）で完走する
- [ ] 429 等の一時エラー時にリトライされる（確認できる場合）

## 3. X (Twitter)

- [ ] タイムラインのツイートに翻訳ボタンが注入される
- [ ] 無限スクロールで新しく現れたツイートにもボタンが付く（MutationObserver）
- [ ] 翻訳実行 → 結果がツイート下に表示。同じツイートの再翻訳はキャッシュから即時表示
- [ ] 設定でTwitter翻訳を OFF → ボタンが出ない / ON に戻す → 再び出る（Observer 再開）

## 4. YouTube

- [ ] コメントに翻訳ボタンが注入され、翻訳が表示される
- [ ] 設定 OFF/ON の切り替えが効く

## 5. 画像翻訳（LM Studio）

- [ ] 画像を右クリック → 翻訳 → 結果表示（LM Studio + vision モデル環境がある場合）

## 7. エラー経路

- [ ] 不正な API キーで検証 → 分かりやすいエラー表示（popup・選択翻訳の両方）
- [ ] ネットワーク遮断状態で翻訳 → エラー表示がクラッシュせず出る
- [ ] **エラー表示・console・保存ログのどこにも API キーが平文で出ない**（フェーズ2以降必須）

## 8. アップグレード互換（フェーズ4・6で必須）

- [ ] リファクタ前バージョンで全プロバイダーの設定を保存したプロファイルに新版をロードし、
      設定（キー・モデル・カスタムプロンプト・機能 ON/OFF）が全て引き継がれる
- [ ] 拡張リロード直後、リロード前から開いていたタブで操作してもコンソールがエラーで溢れない
